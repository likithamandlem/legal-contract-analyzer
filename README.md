# ⚖️ AI Legal Contract Analyzer

An AI-powered legal contract analysis system that uses RAG (Retrieval-Augmented Generation) to analyze, summarize, and answer questions about legal contracts.

## 📌 Features

- 📄 **PDF Upload** — Upload any legal contract in PDF format
- 📝 **AI Summarization** — Get instant contract summaries
- 📋 **Clause Extraction** — Automatically extract key clauses
- ⚠️ **Risk Detection** — Identify high, medium, and low risk clauses
- 💬 **RAG Chatbot** — Ask questions and get answers with source citations
- 🐳 **Dockerized** — Fully containerized for production deployment
